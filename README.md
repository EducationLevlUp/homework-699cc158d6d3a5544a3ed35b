# Stream-режим AI-агента

## Описание

Данное задание демонстрирует переход от единовременного вызова агента
`.invoke()` к потоковому режиму `.stream()` с использованием LangGraph.
Ответ появляется в консоли по мере генерации — токен за токеном, как в
ChatGPT.

## Структура проекта

```
stream_agent.py      # Основной скрипт с потоковым агентом
.env.example         # Шаблон переменных окружения
README.md            # Этот файл
```

## Зависимости

```bash
pip install langchain langchain-openai langgraph langchain-core
```

## Настройка

1. Скопируйте `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```
2. Заполните `OPENAI_API_KEY` вашим ключом OpenAI (или укажите
   `LLM_BASE_URL` для локальной модели через LM Studio / Ollama).
3. При желании измените `AGENT_QUERY` — вопрос, который передаётся агенту.

## Запуск

```bash
python stream_agent.py
```

## Как это работает

### 1. Замена `.invoke()` на `.stream()`

Вместо ожидания полного ответа агент вызывается в потоковом режиме:

```python
stream = agent.stream(
    {"messages": [HumanMessage(content=query)]},
    stream_mode=["messages", "updates"],
)
```

### 2. Два режима стриминга

| Режим       | Что возвращает                                          |
|-------------|---------------------------------------------------------|
| `messages`  | Каждый токен текста по мере генерации                   |
| `updates`   | События об изменениях состояния (вызов инструмента и т.д.) |

### 3. Обработка чанков

Каждый чанк — кортеж `(chunk_type, chunk_data)`:

- **`messages`**: содержит `(message, meta)`. Извлекается `message.content`
  и выводится без перевода строки. При смене `langgraph_step` печатается
  разделитель `\n --- --- --- \n`.
- **`updates`**: содержит словарь с обновлениями состояния. При наличии
  ключа `model` (или `agent`) извлекается последнее сообщение и
  форматируется через `format_message()`.

### 4. Форматирование сообщений

Функция `format_message()` возвращает:
- `message.content` — если есть текстовое содержимое
- `name(args)` — если сообщение содержит вызов инструмента

## Ожидаемый вывод

```
Запрос: Сколько стоит молоко и хлеб в Казани? Сравни цены.

| Продукт | Цена (руб.) | Магазин    |
| Молоко  | 89          | Магнит     |

get_price({'product': 'хлеб', 'city': 'Казань'})
...
```

## Примечания

- **Буферизация вывода**: в условии указан `flush=False`, но для
  немедленного отображения токенов в консоли рекомендуется `flush=True`.
  В коде используется `flush=True`.
- **Ключ метаданных**: в условии указан `meta['langgraph_step']`. В
  некоторых версиях LangGraph может использоваться `langgraph_node`.
  Код обрабатывает оба варианта через `.get()`.
- **Имя узла модели**: в `updates` проверяется ключ `model`, с
  фолбэком на `agent` (зависит от версии LangGraph).
